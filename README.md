# Doodle Bridge

Draw bridges with limited ink so a runaway doodle car can cross the gaps. Mobile web game (PWA).

```
npm install
npm run dev        # local dev server
npm test           # unit + level solver tests
npm run test:e2e   # Playwright mobile smoke test
npm run build      # production build into dist/
```

See PLAN.md for the design and PROGRESS.md for status.
